# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x   | :white_check_mark: |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

To privately report a vulnerability for the `chaos-matters/chaos-master` repository:

1. Navigate to the [Security Advisories tab](https://github.com/chaos-matters/chaos-master/security/advisories/new).
2. Click **Report a vulnerability**.
3. Include a detailed description, steps to reproduce the issue, and the potential impact.

We take all disclosures seriously. You can expect an initial acknowledgment of your report within 48 hours. We will coordinate with you on a timeline for the fix and public disclosure once the patch is released.
